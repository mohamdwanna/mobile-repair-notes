# یادداشت‌های تعمیرات موبایل | Mobile Repair Notes

مجموعه‌ای از یادداشت‌های فارسی برای ثبت مشخصات برد، خواندن مارکینگ قطعات و استفاده از مستندات تعمیرات موبایل.

این مخزن برای هنرجویی نوشته شده که می‌خواهد اطلاعات قطعه را دقیق ثبت کند و نتیجهٔ بررسی خود را به شکلی قابل بازبینی بنویسد. فایل‌های آموزشی و فرم ثبت تعمیر مستقیماً در همین مخزن در دسترس‌اند.

## یک تمرین پیشنهادی

۱. یک برد در دسترس و یک قطعهٔ مشخص انتخاب کنید.
۲. مدل دستگاه، کد برد و تمام نوشته‌های قطعه را ثبت کنید.
۳. با استفاده از مستندات سازنده، نتیجهٔ شناسایی را بررسی کنید.
۴. مشخص کنید کدام اطلاعات مستقیماً مشاهده شده و کدام هنوز فرضیه است.
۵. نتیجه و منبع آن را در فرم ثبت بررسی بنویسید.

برای تمرین شناسایی، نیازی به تعویض قطعه یا اعمال تغذیه به برد نیست. هدف این مرحله، جمع‌آوری اطلاعات قابل اتکا است.

## ارتباط این پروژه با وب‌سایت

این یادداشت‌ها برای پروژهٔ [آی‌سی تو موبایل](https://ictomobile.com/) تهیه شده‌اند. وب‌سایت برای جست‌وجوی مدل گوشی و اطلاعات قطعات برد استفاده می‌شود؛ آموزش‌ها و فرم‌های این مخزن به‌صورت مستقل قابل مطالعه هستند.
